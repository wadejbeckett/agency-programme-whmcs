# Security

Please report security problems in Agency Programme for WHMCS privately, through a GitHub security advisory on this repository (Security > Report a vulnerability), rather than in a public issue. Include the module version, the WHMCS and PHP versions, and steps to reproduce.

Reports are acknowledged as soon as possible and a fix is published with a changelog entry once it is ready. The addon only ever adds invoice lines and writes to its own `mod_agencydiscount_*` tables; a report that shows it changing anything else is treated as high priority.
